# 🔒 Plataforma de Segurança Digital

Aplicativo web educacional completo sobre conscientização em cibersegurança desenvolvido em português brasileiro.

## 🎯 Funcionalidades Principais

### 📚 Módulos Educacionais
- **Phishing**: Aprenda a identificar e evitar tentativas de fraude
- **Senhas Seguras**: Crie e gerencie senhas fortes
- **Engenharia Social**: Entenda táticas de manipulação
- **Ransomware**: Proteja-se contra sequestro de dados

### 🎮 Sistema de Gamificação
- **Níveis e Pontos**: Sistema progressivo de XP
  - 100 pontos por módulo completado
  - 50 pontos por quiz perfeito (100%)
  - 25 pontos por passar de primeira
  - 10 pontos por tentativa de quiz

- **Conquistas Desbloqueáveis**: 10 achievements únicos
  - Primeiro Passo (25pts)
  - No Caminho Certo (50pts)
  - Excelência (50pts)
  - Expert em Segurança (100pts)
  - Perfeição Absoluta (75pts)
  - Aprendiz Veloz (40pts)
  - Mestre Absoluto (150pts)
  - Dedicação Total (100pts)
  - Persistência (30pts)
  - Colecionador de Pontos (50pts)

### 📊 Dashboard de Progresso
- Visualização do nível atual e pontos
- Barra de progresso para próximo nível
- Estatísticas detalhadas por módulo
- Conquistas desbloqueadas e bloqueadas
- Média geral de performance

### 🏆 Sistema de Ranking
- Leaderboard global (mockado)
- Comparação com outros usuários
- Visualização de posição no ranking

### 📜 Certificados Digitais
- Geração automática de certificados
- Download em formato PNG
- Certificados personalizados por módulo
- Inclui pontuação e data de conclusão

### 🌓 Modo Escuro
- Toggle entre tema claro e escuro
- Persistência da preferência
- Design otimizado para ambos os modos
- Transições suaves

### 💾 Persistência de Dados
- LocalStorage para salvar progresso
- Dados persistem entre sessões:
  - Módulos completados
  - Pontuações dos quizzes
  - Pontos totais e nível
  - Conquistas desbloqueadas
  - Tentativas de quiz
  - Data do último acesso

### 📝 Quiz Interativo
- 5 questões por módulo
- Feedback visual imediato
- Pontuação mínima de 70% para passar
- Sistema de tentativas múltiplas

### 💡 Dicas Rápidas
- 8 categorias de segurança
- Mais de 40 dicas práticas
- Organização por tópicos

## 🎯 Objetivos Pedagógicos

O aplicativo foi desenvolvido seguindo princípios de IHC (Interação Humano-Computador):

- **Usabilidade**: Interface intuitiva e fácil de navegar
- **Acessibilidade**: Design inclusivo para diferentes usuários
- **Feedback**: Resposta visual clara para todas as ações
- **Consistência**: Padrões de design mantidos em todo o app
- **Prevenção de Erros**: Validações e confirmações
- **Flexibilidade**: Múltiplas formas de navegar
- **Estética**: Design moderno e profissional

## 📖 Como Usar
